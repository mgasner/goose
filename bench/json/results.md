# JSON benchmarks

Measured 2026-10-09 on Darwin arm64, clang 21.0.0; load average 14.1 when the run started. Best of 50 runs each. Generated by `bench/json/json_bench.py`; the design is `docs/design/json.md`.

| citm_catalog.json | 1.73 MB | 3881 | 4921 | 79% | 3146 | 4202 | 75% | 1534 | 4811 | 32% |
